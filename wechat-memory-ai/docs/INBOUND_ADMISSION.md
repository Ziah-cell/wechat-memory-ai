# 普通窗口接入条件

2026-10-12 当前：已删除最小化入站能力接口及内部采集程序。只保留正常打开窗口的普通读取。联合视觉出现候选和随机标记准入不等于无人值守可靠来信。

进入真实回复核心前，需要分别验证：窗口与联系人绑定、明确收发方向、历史/新到达边界、跨重启去重策略、发送前目标复核、不抢焦点发送，以及停止时撤销尚未交付的动作。每项缺失都必须明确拒绝，不能借用模型猜测。

当前窗口实例绑定只是限制读取范围；ReadOnlyWeChatSource 不写记忆、不调用模型、不发送。用户现已选定此前可读的旧测试号，非前台、部分遮挡下静态正文读取已通过；新号仍无可绑定标识，结果不能混用。旧号本次只有方向候选，历史边界未知；输入框可写和按钮支持 Invoke 仅为元数据，未执行写入或发送。详见 [实测](OPEN_WINDOW_VALIDATION.md)。

旧最小化诊断结果留在 [历史记录](history/INBOUND_ADMISSION-before-window-open.md)，接口、源码与旧命令已退出当前产品。
