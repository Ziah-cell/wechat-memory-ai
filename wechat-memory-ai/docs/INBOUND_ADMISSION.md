# 普通窗口接入条件

2026-10-14 当前：已删除最小化入站能力接口及内部采集程序。只保留正常打开窗口的普通读取。联合视觉出现候选和随机标记准入不等于无人值守可靠来信。

进入真实回复核心前，需要分别验证：窗口与联系人绑定、明确收发方向、历史/新到达边界、跨重启去重策略、发送前目标复核、不抢焦点发送，以及停止时撤销尚未交付的动作。每项缺失都必须明确拒绝，不能借用模型猜测。

当前窗口实例绑定只是限制读取范围；ReadOnlyWeChatSource 不写记忆、不调用模型、不发送。用户现已选定此前可读的旧测试号，非前台静态正文读取通过（579/580），随后受监督遮挡双来信检查通过（591）：两条同文各交付一次，5 次轮询无重复，关闭后失效，同一内存绑定重开来源 3 次基线零回放。605 分步检查又完整验证同一来源内的自身新消息过滤和好友后来信交付：分别过滤 1 条、交付 1 次，各自后续 5 次无重复，关闭后候选失效。598/601 新标记方向未知导致停止，连续准入稳定性仍未通过。新号仍无可绑定标识，结果不能混用；任意历史同步、持久去重和联系人身份仍未验证。输入框可写和按钮支持 Invoke 仅为此前元数据，未执行写入或发送。详见 [实测](OPEN_WINDOW_VALIDATION.md)。

旧最小化诊断结果留在 [历史记录](history/INBOUND_ADMISSION-before-window-open.md)，接口、源码与旧命令已退出当前产品。
