# GitHub 阶段更新约定

2026-10-01 用户明确授权：先做免费版本，每完成一个可验收阶段，由开发者直接提交并上传到用户指定的 GitHub 仓库，后续在同一仓库持续更新；不再以下载修订包作为交付流程。

## 阶段完成条件

1. 对照本阶段要求完成代码和必要测试；运行 `scripts/windows.ps1 -Action test`（其他平台用 `python scripts/test.py`）。
2. 更新 STATUS.md 和 TEST_RESULTS.md，区分 mock、真实客户端、真实模型和未验证项目。
3. 检查待提交清单：只含源码、测试、示例配置、必要文档和脱敏证据；不包含个人配置、密钥、聊天数据、运行日志、备份、缓存或构建包。
4. 创建有明确阶段说明的 Git commit，推送到已绑定的远程分支；核对远程提交 SHA 与本地一致。
5. 向用户提供仓库/提交链接、阶段结果和下一步，不再要求重新下载 ZIP。

目标为用户账号下独立的私有仓库 `Ziah-cell/wechat-memory-ai`，本地分支 `implementation`。现有其他项目不改动。目标固定后，不重复询问是否允许常规阶段提交和推送。若远程出现新提交，先读取并保留，不使用强制推送覆盖。

这是当前项目的开发交付约定，不会创建后台同步程序、定时任务或持续运行的 Agent。真实发送、模型服务授权及系统级变更仍按各自实际步骤处理。默认不启用可能消耗额度的 GitHub Actions；本地验证通过后再推送。

## 本地目录结构

Git 根目录是 `vx.agent`；应用在 `wechat-memory-ai/`。从仓库根目录进入该子目录后，按 README 运行。旧 ZIP 与 PACKAGE_MANIFEST.json 仅是此前本机打包记录，Git 忽略它们；后续以 Git commit 和测试证据标识版本。
