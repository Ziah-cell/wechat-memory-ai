# 自然聊天、延迟与记忆的接入要求

2026-10-03用户新增要求：延迟不高、少AI腔、能接续聊天并记住偏好，像平常聊天一样交流。本文件记录产品要求与实现进度，不向实际聊天记忆库写入用户资料。v0.1.14已增加DeepSeek请求适配和自然聊天提示，尚未调用真实模型，微信消息源与实际记忆/自动回复仍未接通。

## 建议的首个模型候选

建议先评估`deepseek-flash`的非思考模式。官方当前模型为DeepSeek-V4.1-Flash；Chat Completions支持显式`thinking.type=disabled`，默认则开启思考。来源：[模型说明](https://api-docs.deepseek.com/quick_start/pricing/)、[思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)、[请求格式](https://api-docs.deepseek.com/api/create-chat-completion/)，核对日期2026-10-03。

现已按上述建议实现`provider="deepseek"`专用格式：明确发送`thinking.type=disabled`，输出上限映射为`max_tokens`，不传`store`或`reasoning_effort`，并用本地假服务验证；通用`chat_completions`保持原格式。配置草稿仍使用fake、关闭网络，未更改个人配置或调用真实API；不据此声称真实延迟或自然度达标。详细接入条件见[DEEPSEEK.md](DEEPSEEK.md)。

低延迟方案先保持单次回复调用，日常短回复、有限近期上下文与按需相关记忆；避免每一轮在回复前串行调用另一个模型整理记忆。记录本机从消息接纳到完整回复可用的时间、模型请求耗时及失败率，报告中位数和较慢请求范围。微信一次发送完整文本时，首字流式时间不等于用户看到回复的时间。当前没有真实测速，不能承诺固定秒数。

## 聊天风格

- 日常消息优先一到三句，随话题和用户消息长度调整；用户询问复杂问题或要求详细说明时展开，不硬截断成残句。
- 承接当前话题，不每轮重复招呼、复述问题、列清单、做总结或问“还有什么可以帮助你”。
- 不主动做说教和心理分析；是否给建议取决于用户是在闲聊、吐槽还是求解。
- 只有有用时才提及旧事和偏好，不每次说“根据你的偏好”；没有记录就不编造共同经历。
- 口语、语气词和表情保持适度，跟随用户偏好，不靠故意错别字或随机延迟伪装真人。
- 允许温暖自然的交流，保持真实身份表述；不擅自设定恋爱关系或虚构现实行动。

虚构的风格例子：已知样例用户偏好清淡，询问晚饭时，可以说“来碗番茄鸡蛋面怎么样，清淡一点。”不必先解释记忆系统如何检索。这只是测试样例，不是实际用户偏好。

## 记忆分层与修正

近期对话负责接续正在说的话；较早的重要话题需要带来源的摘要；稳定偏好和明确的重要经历单独持久保存，按当前话题取用。模型更换不应删除本地记忆。云模型生成时需要接收本轮正文和选中的上下文；本地保存不表示这些片段从不发送给服务商。

用户不应必须每次输入命令才能被记住。后续可从明确的日常表达提取低风险偏好，例如虚构样例“我喝咖啡不加糖”，记录原话来源、时间和确定程度；不能从一次情绪、玩笑、引用或模型自己的回复推断稳定人格。模糊信息保持候选，矛盾事实不同时当作真，新的明确纠正覆盖旧值。敏感信息不自动形成长期资料。

“别再记这个”“我现在改了”等自然修正应可作用于对应记忆；删除同时清理会话上下文、相关摘要及后续派生结果，并遵守独立遗忘账本，不能从旧备份或迟到的提取结果重新写回。明确的查看、纠正和删除入口继续保留。

## 已有能力与下一步

当前`Engine.context`能组合配置中的语气/风格、结构化记忆、旧历史摘录和近期对话，按字符预算裁剪。系统提示已加入日常一到三句、按复杂度展开、少套话、不默认列清单或总结、不主动说教，以及自然使用相关已知记录、不编造经历或身份的要求；配置和用户当前明确要求可以调整默认表达习惯，明确更新的偏好优先于默认配置。这些是生成指导，实际自然度仍待模型评估。DeepSeek专用分支拒绝服务端截断或超长回复，不将半句话交付；原通用分支保留既有字符裁剪。`MemoryService`只支持明确记忆指令及有限称呼纠正；普通聊天不会自动成为长期偏好。旧摘要是有来源的截断摘录，不能称为语义总结或完整聊天记忆。上述核心只在模拟适配器工作；`ReadOnlyWeChatSource`不会将真实候选送入其中。

离线配置与请求参数测试已补齐。后续用虚构对话评估：跨轮接话、隔轮偏好使用、旧值纠正、临时心情不固化、未知信息不编造、删除后不能从摘要/备份重新出现。只有实际模型无发送评估才能检验自然度与延迟；纯单元测试不等同于聊天质量验收。真实记忆与自动回复接通仍受当前阶段边界约束。
