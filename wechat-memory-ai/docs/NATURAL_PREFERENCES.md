# 日常明确偏好的本地记忆

v0.1.16在现有模拟聊天核心中增加有限的日常表达识别。目标是让常见偏好无需每次输入记忆命令，同时保留可核对的来源和删除边界。它不是通用语言理解：只接受已列入规则的完整句式和有限取值，其他内容继续作为普通聊天，不自动形成长期资料。

## 可以使用的表达

下列均为虚构示例，不是用户实际偏好。

| 表达 | 行为 |
| --- | --- |
| 我平时喜欢喝热柠檬水。 | 保存饮品偏好，继续正常生成一次聊天回复 |
| 我喝咖啡不加糖。 | 保存咖啡加糖偏好，继续正常生成一次聊天回复 |
| 以后回复我简短一点。 | 保存长期回复长度要求，继续正常生成一次聊天回复 |
| 我的饮品偏好改成温乌龙茶。 | 本地纠正明确指定的偏好，不调用模型 |
| 忘记我的饮品偏好。 | 本地遗忘明确指定的偏好，不调用模型 |
| 我平时最喜欢喝什么？ | 查询当前明确饮品记录；没有就说明不确定，多条则不选 |

饮品取值目前仅支持茶、热柠檬水、温乌龙茶、乌龙茶、绿茶、红茶、白开水、咖啡、美式咖啡、冰美式、拿铁；咖啡加糖归一为不加糖、少糖或正常糖，回复长度为简短或详细。规则外的值仍可用原有明确记忆命令保存。

日常陈述在保存后进入同一轮模型上下文，不另调模型提取，也不把模型自己的话变成用户偏好。识别成功不代表云模型必然遵循偏好；真实聊天自然度仍需要独立验收。

## 写入、纠正与遗忘

只有通过既有消息过滤、身份检查、敏感信息检查和预算检查的普通陈述才会自动保存。自身消息、历史消息、其他会话和暂停状态不会触发提取。模型请求失败时，已经接受并保存的明确用户事实仍保留；失败不会自动重试。

记录沿用现有结构，保存会话、键、值、明确程度、事件来源及时间。重复表达同一值不改写记录，也不清除上下文。已有唯一兼容键时沿用原键；多个别名记录或类型冲突时先澄清，不自行合并或选择。本地澄清不发模型请求，也不预留调用预算。

纠正和遗忘沿用独立遗忘账本：删除旧值，同时保守清理该会话此前历史和摘要。使用最新账本恢复旧备份也不会使旧值重新可用；旧备份不包含的新值不会凭空补回。明确管理命令可以在模型调用额度已用完时执行。

## 尚未覆盖

带引用、假设、临时状态、否定或多句混合等额外结构、因而未匹配完整规则的表达不自动提取。规则不能识别恰好符合支持句式的玩笑或反讽意图。“忘记这个”之类指代不清的要求不能据此定位记录。不能把不匹配的表达视为没有偏好，也不能根据缺少记录断言用户从未说过或某条记录已经删除。

目前只覆盖饮品、咖啡加糖和回复长度三个主题。其他个人事实、任意自然语言纠正/遗忘、语义摘要和全面防编造仍未完成。真实微信消息源没有接入此核心，自动回复保持关闭。

本轮验证只使用临时虚构数据和假模型；未新增真实API请求、实际聊天记忆或微信发送。测试范围及实测限制见[TEST_RESULTS.md](TEST_RESULTS.md)，聊天整体要求见[CHAT_EXPERIENCE.md](CHAT_EXPERIENCE.md)。
