# 普通个人好友私聊接入路线

2026-10-12 用户已取消最小化。当前目标是 Windows 微信正常打开、允许非前台/遮挡，不置顶、不周期性激活、不抢焦点。旧内部采集研究已删除，现行路线仅为普通窗口 UIA/视觉接入。

顺序：恢复并核验已授权独立窗口的普通 UIA 标识 → 非前台/遮挡只读样本与新到达验证 → 稳定联系人和方向/历史边界 → 不抢焦点的发送能力及发送前复核 → 接入已有 Engine/模型/记忆。真实模型和发送操作最后确认。

当前只读源不是完整真实适配器，send 始终拒绝。不能用可见文本、昵称、RuntimeId 或正文哈希代替联系人认证和服务器消息 ID；不能用 PrintWindow 成功代替消息方向正确。未解决条件见 [窗口实测](OPEN_WINDOW_VALIDATION.md)。

旧研究报告只保留历史，不是可继续执行的候选计划。详见 [旧路线归档](history/PERSONAL_ACCOUNT_ROUTE-before-window-open.md)。
