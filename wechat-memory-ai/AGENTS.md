# 项目开发约定（2026-10-12 当前）

用户已取消全部微信最小化方案。微信保持正常打开，可非前台、可被遮挡；不置顶、不周期性激活、不抢焦点。不再开展 Hook、内部数据库、原生 trampoline/共享环缓冲等被取消路线的研究。旧指令与检查点仅为历史，不能覆盖本文件和用户最新要求。

- 工作目录为本项目 wechat-memory-ai；分支 implementation。本任务不创建新任务/工作树、不使用子代理。
- 普通读取只保留 UIA 与现有联合视觉路径。发现最小化即停止；不自动恢复、重绑或回放。selection/background 及其最小化诊断接口已删除，不重新引入。
- 保留长期记忆、有限自然偏好、会话隔离、模型适配、去重及暂停/停止。默认 fake、网络关闭、real_send=false，当前自动回复未启用。
- 真实模型调用、真实发送及自动回复启用保留用户最终确认边界。常规本地开发、离线测试、当前指定窗口只读验证、提交推送已授权，无需再问。
- 仅检查用户授权的唯一独立测试好友窗口。绑定是窗口实例限制，不等于联系人身份认证；无可信方向/历史/发送验证时不能接入 Engine。不要读取密钥、真实聊天库，不使用 Jev 或其他判断模型。
- 不记录正文、联系人昵称、绑定身份、密钥或外部异常内容。保留个人配置/.env/真实数据；data 与备份不提交。
- 不重试此前被拒的 MSAA 和原生合成位图路线。4 类 13 项既有原生测试已显式 skip；不要为了“全通过”删除或绕过 skip。
- Python >=3.11，核心和测试使用标准库。回归：python scripts/test.py。测试以虚构配置和临时数据运行，不能加载个人 .env。
- Windows 删除前校验每个绝对目标位于本项目；按精确清单删除。旧实验只保留历史报告及原始数据，旧源码哈希不再可用作当前校验。
- 记忆遗忘清除会话上下文/摘要，并保留独立遗忘账本；恢复不能覆盖账本。模型无工具、shell、文件或配置修改权限。
- Git 常规提交推送 origin implementation 已授权。push/ls-remote 使用 git -c http.sslBackend=openssl；不关闭证书验证、不强推、不切分支。不再制作分发 ZIP。
